2 · Website changes — ✅ already LIVE

Nothing left for you to do on the site. I shipped the traffic-split update to neurovitol.shop (commit b8fc058). Tested in 6 scenarios: ads desktop, ads iOS, deep navigation, pure SEO, stripped auto-tagging, VSL slot.
  • Both affiliate links now carry ?source_id={source_id}&sub1={gclid}&sub2={gbraid}&sub3={wbraid}.
  • Ads visit detection: any of gclid / gbraid / wbraid on the landing URL — or the explicit src=ggax suffix — flips the session to source_id=ggax. The verdict + ids persist in sessionStorage, so a visitor who lands on a vs-page from an ad, browses 4 pages, then clicks a CTA still hands off as ggax with the click id intact.
  • Everything else (SEO, direct, social) automatically hands off as source_id=orga with empty subs.
  • iOS: Apple's ATT strips gclid on iOS Safari. Google instead auto-tags with gbraid (web→web) or wbraid (web→app). Both are captured and forwarded in sub2/sub3 — that's what makes manual conversion upload possible for ~30% of US clicks you'd otherwise lose.

3 · Account setup & tracking settings

  1. Auto-tagging ON — Admin → Account settings → Auto-tagging → "Tag the URL that people click through from my ad" ✅ (this is what appends gclid/gbraid/wbraid).
  2. Account-level Final URL suffix — Admin → Account settings → Tracking → Final URL suffix:
  1. Auto-apply recommendations OFF — Recommendations → Auto-apply → untick everything. (Google will otherwise add broad match + "enhanced" CPCs that wreck affiliate margins.)
  2. Every campaign: Search Network only — untick "Google search partners" and "Display Network".
  3. Location: United States · Location options → Presence (not "presence or interest").
  4. Language: English.
  5. Account goal: only the imported NV Purchase conversion (section 4) set as Primary. Remove/secondary everything else (page views, GA imports, etc.) so smart bidding optimizes purely to sales.

4 · Conversion tracking — Google Sheets manual import

The sale happens on the offer page (not your domain), so Google can't see it. You close the loop by uploading conversions from the network's report back into Google Ads. You said your Sheet + export are ready — here is the exact wiring:

4a · Create the conversion action (one time)

  1. Google Ads → Goals → Conversions → + New conversion action → Import → "Other data sources or CRMs" → Track conversions from clicks.
  2. Settings: Name NV Purchase · Category Purchase · Value: Use values from your data (fallback $200) · Count One · Click-through window 90 days · set as Primary.

4b · Sheet format (the 5 columns Google expects)

  • Google Click ID: paste whichever id the network passed back — sub1 (gclid) → if empty use sub2 (gbraid) → if empty use sub3 (wbraid). Google accepts all three in this same column. This is the iOS answer: gbraid/wbraid rows ARE your iOS conversions.
  • Conversion Name: must exactly match NV Purchase.
  • Conversion Time: must be AFTER the click. Format yyyy-MM-dd HH:mm:ss-05:00 (use the network report's timestamp + your account timezone offset).
  • Only upload rows where source_id=ggax. Never upload orga rows — they have no click id and would error out anyway.

4c · Hook the Sheet to Google Ads (one time, then it's automatic)

  1. Goals → Conversions → Uploads → + → source Google Sheets → link your sheet.
  2. Set Schedule: Daily (pick a time after your daily network export lands in the sheet).
  3. Each day: export ggax conversions from lckhighepcs → paste/append into the sheet → Google pulls them automatically. Check the Uploads page for row errors the first week.
Rhythm: upload daily. Conversions can be imported up to 90 days after the click, but smart bidding learns fastest on fresh data — same-day or next-day uploads make Maximize Conversions usable weeks earlier.

11 · Compliance guardrails (supplement = never a cure)

  • NeuroVitol is a dietary supplement. Ads may say "supports memory & focus" — never "treats / cures / prevents" anything. All disease terms (dementia, Alzheimer's, ADHD, …) are blocked in the shared negative list and must never appear in keywords or ad text.
  • No competitor trademarks in ad text (keywords OK in the US).
  • No "guaranteed results", no before/after cognition claims, no medical-professional impersonation. "60-Day Money-Back Guarantee" is fine — it's a refund policy, not a results claim.
  • Ads point to neurovitol.shop (your own pre-sell with full FDA disclaimer, contact info, legal pages) — not to the raw affiliate link. That's exactly the destination quality Google wants; no cloaking, no redirect tricks.
  • "Up to 60% off" matches the live offer-page pricing — keep ad claims synced if the offer changes.
